# Katsuki Editors

This repository is for any editors I make or have made for Akiba's Trip Undead & Undressed

Any future software for this repository will be written in Dart and have 0 dependencies.

# Katsuki's Textworks

Katsuki's Textworks is used for modding text, dialogue, etc for Akiba's Trip Undead & Undressed. 

Double click the executable and ideally, read the Usage Docs (click the G sphere) within the software but i'll quickly explain how to use it (a lot of the code is repurposed from my Awano's Easy Life Tools):

To move the app around you must use right click on the GUI (the vertical buttons or the title of the app).

To exit out of Katsuki's Textworks, click the esc button on your keyboard.

Press F1 to toggle on/off always on top mode.

Editor panels can be moved by dragging their title bars.

For more details review Usage Docs within the software. Sauce folders are just the source files of the executables I make, modders/gamers should use the executables
